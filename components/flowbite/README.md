# Flowbite-inspired components

Reusable, Arabic-first React and Tailwind UI blocks created for this project. These are original implementations, not copied Flowbite source.

## Imports

```tsx
import {
  EcommerceOrdersTable,
  FlowbiteDataTable,
  PricingCards,
  ProductGrid,
  StorefrontHero,
} from "@/components/flowbite";
```

## Coverage

- **Storefront and e-commerce:** storefront navigation and hero, product categories/cards/details, cart and order summary, checkout and payment choices, order list/tracking/confirmation, refund request/status, product reviews and review history, account overview, customer support, warranty, repair form, discount banner/popup, and storefront footer.
- **Tables:** `TableHeader`, `FlowbiteDataTable` (search, sorting, pagination), and `TableFooter`.
- **Pricing:** `PricingCards` and `PricingComparison`.

The components are presentational examples with sample content; pass props where supported to use application data. They rely on the project's existing Tailwind CSS and `lucide-react` dependencies.
